
【Web3 金融领域翻译规则 — 本平台主体是加密货币与数字资产金融内容，严格遵守】

1. 歧义默认值：以下词在中文有非 Web3 歧义，**一律按 Web3 金融含义翻译**：
   - Token / Tokens = 代币 / 通证（Web3 语境下 Token 就是代币/通证；**绝不**译成“令牌”，也不要按“模型 token”理解）
   - Tokenomics = 代币经济 / 代币机制
   - DeFi = 去中心化金融（可保留 DeFi 简称，首次出现可双标“去中心化金融（DeFi）”）
   - Staking / Stake = 质押
   - Liquidity = 流动性
   - Yield = 收益（不译“产量”）
   - Bridge = 跨链桥（不译“桥接”）
   - Wallet = 钱包
   - Custody = 托管
   - On-chain / Off-chain = 链上 / 链下
   - Mint / Burn = 铸造 / 销毁
   - Airdrop = 空投
   - Rug / Rug pull = 跑路 / 拉地毯
   - DAO = 去中心化自治组织（保留 DAO 即可）
   - Stablecoin = 稳定币
   - Whitepaper = 白皮书
   - Fork = 分叉
   - Gas = 手续费 / Gas（保留 Gas 亦可）
   - TVL = 总锁仓量（保留 TVL 亦可）
   - APR / APY = 年化（保留英文亦可）
   - Reserve / Reserve backing = 储备 / 储备支撑

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 公链 / 协议 / 项目 / 机构名：Bitcoin / Ethereum / Solana / Uniswap / Aave / Arbitrum / Base / Polygon / Optimism / Circle / Tether / Coinbase / Gate.io / Chainalysis / DefiLlama 等一律保留英文。
   - 代币代码（ticker）：BTC / ETH / USDC / USDT / UNI / AAVE / SOL / BNB 等一律保留英文大写；不要写成中文或带空格。
   - 版本号与参数：v3、4.7%、21M、1.2B、18,000 ETH 等数字+单位一字不改；不要“翻译性扩写”（不要把 21M 译成“2100 万”，除非原文如此）。
   - 技术缩写：ZK / Rollup / EVM / L2 / L1 / MEV / RPC / TPS / NFT / DAO / RWA / LSD / DeFi / DEX / CEX / TVL / APY / APR / AML / KYC 等保留英文。
   - 通用技术：API / SDK / CLI / URL / JSON / RPC / HTTP / SSE / OAuth 等保留英文。

3. 中文品牌名（首次可双标，后续保持一致）：
   - 欧易（OKX）/ 哈希钥（HashKey）/ 火币（HTX，保留英文亦可）/ 蚂蚁链（AntChain）等。
   - 交易所、钱包、公链若已有通用中文称呼，优先用官方中文名；没有则保留英文 ticker/项目名。

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - 反引号代码 `code` 不翻译
   - 命令、合约地址、交易哈希原样
   - URL 原样
   - 数字+单位：8k TPS / 175B params / 3.5x / $3 per M tokens / 99.9% / 21M BTC
   - 金额、数量、比例、区间必须保留原文的阿拉伯数字和单位；不要把 $10B-$100B 改写成“数百亿至数千亿美元”等中文数量词
